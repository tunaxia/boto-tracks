# Boto Tracks by Tunaxia

[Boto Tracks](https://boto-tracks.tunaxia.com/) is a modern, fast, and searchable interface for tracking changes, fixes, and features in the AWS SDK for Python (Botocore and Boto3).

Developed by **Tunaxia**, this tool provides "Changelog Intelligence" for AWS developers who need to stay updated with every Botocore release without digging through raw text files.

For more information, visit [tunaxia.com](https://tunaxia.com/).
