# Boto Tracks by Tunaxia

[![Daily Boto Changelog Sync](https://github.com/tunaxia/boto-tracks/actions/workflows/daily_sync.yml/badge.svg?event=schedule)](https://github.com/tunaxia/boto-tracks/actions/workflows/daily_sync.yml)
[![CodeQL](https://github.com/tunaxia/boto-tracks/actions/workflows/codeql.yml/badge.svg)](https://github.com/tunaxia/boto-tracks/actions/workflows/codeql.yml)

Boto Tracks is a modern, fast, and searchable interface for tracking changes, fixes, and features in the AWS SDK for Python (Botocore and Boto3).

Developed by **Tunaxia**, this tool provides "Changelog Intelligence" for AWS developers who need to stay updated with every Botocore release without digging through raw text files.
